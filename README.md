# Duwamish

## The VAX side of *A Lost Traveller*

[`vax/`](vax/README.md) contains Alan Fredericks' 1985 VAX MACRO program, which
renders a musical manuscript directly into Compact Disc audio. It runs on
MiniVMS, a small VMS-like operating system written for this project, on an
emulated MicroVAX II / VAXstation II, and comes with a MACRO-32
cross-assembler. Two tracks of the album are rendered on the emulated VAX, and
MP3 previews are in [`vax/album/preview/`](vax/album/preview/).
